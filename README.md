# 📝 To-Do List Web App

A simple and responsive To-Do List application built using **HTML**, **CSS**, and **JavaScript**. This project allows users to manage their tasks effectively by adding, marking as completed, deleting tasks, and saving them to **local storage** so they persist even after refreshing the page.

## 🚀 Features

- ✅ Add new tasks
- ❌ Cross off (mark as completed) tasks
- 🗑️ Delete tasks
- 💾 Save tasks in **local storage**
- 🔁 Persistent data across sessions
- 📱 Mobile responsive layout

## 🛠️ Tech Stack

- **HTML5** – Structure of the app
- **CSS3** – Styling and layout
- **JavaScript** – Interactivity and logic
